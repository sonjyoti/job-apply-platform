# Job Apply Platform

An automated job application platform that finds relevant job opportunities, compares them with a user's profile and resume, and helps automate the application process.

## Planned Features

- Create and manage a candidate profile
- Add skills, education, experience, and projects
- Upload a resume
- Scrape job listings from supported sources
- Match jobs with the candidate's profile and resume
- Calculate job relevance scores
- Filter jobs based on preferences
- Track job applications
- Automate applications where supported

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL

### Frontend
- React
- Vite
- Tailwind CSS

### Planned
- Python for job scraping
- Redis
- AI/NLP for improved job matching
- Playwright for supported application automation
